# Free College Scholarships & Financial Aid Directory

A freebies directory of free scholarship and financial aid resources for students and families: application tips, essay help, a deadline tracker, and financial aid office guidance. Official links only; education only.

Built and published by **Asdale Dynamics, LLC** (Indiana, formed October 2026) — beginner-friendly education resources from Dylan Asdale, registered nurse turned AI author and founder of Asdale Dynamics, LLC.

## What's inside

- `src/` — Markdown source pages
- `site/` — generated static HTML site (client-side search, no build step required to view)
- `build.py` — regenerates `site/` from `src/`
- `LICENSE` — MIT License, Copyright (c) 2026 Asdale Dynamics, LLC

## How to run

Open `site/index.html` directly in a browser, or serve the folder locally:

```bash
python3 -m http.server --directory site 8080
```

Then visit http://localhost:8080. Client-side search works with or without a local server.
