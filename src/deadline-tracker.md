# Financial Aid Deadline Tracker

Copy these dates into your own planner, phone, or spreadsheet. Deadlines change — always confirm on the official program page.

## Federal deadlines

| Item | Typical date | Notes | Official source |
|---|---|---|---|
| FAFSA opens | October 1 | File as early as possible | [fafsa.gov](https://fafsa.gov) |
| Federal FAFSA deadline | June 30 | End of the school year | [studentaid.gov](https://studentaid.gov) |
| FAFSA corrections due | September (following year) | Last chance to make corrections | [studentaid.gov](https://studentaid.gov) |

## College and state deadlines

| Item | Typical date | Notes |
|---|---|---|
| CSS Profile | Varies by college | Check each college's financial aid page |
| State grant deadlines | Varies by state | Often earlier than federal deadlines |
| College priority deadlines | December–March | Check each college's website |
| Scholarship deadlines | October–March | Varies by program |
