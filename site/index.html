How to use this directory

  1. Start with the FAFSA — it unlocks federal grants, work-study, and loans.
  2. Browse the scholarship directory and note deadlines in the tracker.
  3. Draft essays with the essay help page and get recommendations early.
  4. Contact your school's financial aid office with questions — they are there to help.
